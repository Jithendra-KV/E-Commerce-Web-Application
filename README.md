# Sunday Supply

A responsive e-commerce storefront inspired by the linked PHP/MySQL project demo. The current build is a self-contained front-end prototype: product browsing, category filters, search, sorting, favorites, and a persistent shopping bag work in the browser.

## Run it

Open `index.html` in a browser, or serve this folder with any static file server. Product images and web fonts load from external URLs and need an internet connection.

## Demo behavior

- The cart and favorites are saved in browser `localStorage`.
- Checkout and newsletter signup are interface demos only; no payment or email is submitted.
- Products are defined in `script.js`. This prototype does not connect to PHP or MySQL yet.
